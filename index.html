Methodology & formula reference

Card 01 — Sample size
n = z²·p(1−p)/e² or n = z²·σ²/e²
Cochran's formula. z is the critical value for your confidence level (1.645 / 1.96 / 2.576). For proportions, p = 0.5 maximises required n and is the safe default. Finite-population correction and design effect adjustments applied in sequence as shown.
Card 02 — Sampling design
proportional: n_h = n · N_h/N
Neyman: n_h = n · N_h·S_h / Σ N_h·S_h
DEFF (cluster) = 1 + (m−1)·ρ
Neyman minimises variance for a fixed n given the S_h. Allocations are rounded using the largest-remainder method so n_h are integers summing to n; any stratum whose allocation exceeds N_h is capped and the remainder redistributed.
Card 03 — Power analysis
two proportions: n per group = (zα/2 + zβ)² · [p₁(1−p₁) + p₂(1−p₂)] / Δ²
two means: n per group = 2(zα/2 + zβ)² · σ² / Δ²
Normal approximations for planning. MDE mode solves the same equations for the smallest detectable effect at a given n.
Card 04 — AAPOR response rates
RR1 = I / (I+P+R+NC+O+UH+UO)
RR3 = I / (I+P+R+NC+O+e(UH+UO))
COOP2 = (I+P) / (I+P+R+O)
CON1 = (I+P+R+O) / (I+P+R+O+NC+UH+UO)
The five response-rate definitions differ only in how they handle partial interviews (in or out) and unknown eligibility (denominator-inflating or probabilistically allocated via e). RR1 is the most conservative, RR5 the least. AAPOR recommends reporting all five or, at minimum, RR3 and COOP2 for most telephone and face-to-face surveys. Release size = target completes ÷ expected RR.
Card 05 — Design weights
w_h = N_h / n_h
DEFF_w = n_total · Σ(N_h²/n_h) / N_total²
The design weight is the inverse of the inclusion probability, which simplifies to population ÷ respondents within each stratum. Non-response is already netted out because n_h is the number of completes, not the number of issued units. Post-stratification replaces N_h with an external control total from a census or benchmark survey. The Kish design effect measures how much precision unequal weights cost relative to a simple random sample of the same size — a value above 3 usually warrants trimming extreme weights or collapsing sparse strata.
What this does not model. Card 05 returns a single weight per stratum; in practice, weights vary within strata due to differential non-response and coverage, and are typically trimmed or winsorised before use. Raking (IPF) is not implemented here — it requires marginal control totals and iteration. Multi-stage designs compound weights across stages. Variance estimation under complex designs (linearisation, jackknife, BRR) belongs in analysis software, not in this calculator.
